## Checks the simulation makes

- ScopeCheck full-length set (tender + 2 quotations): recorded token usage from SC-T12 fresh set, 12 requests (raw logs in samples/benchmark-results). Cap check: none.
- ScopeCheck small set (RFQ + 2 quotations): recorded token usage from live-repeat-rfq, live-repeat-quote-a, live-quote-b (2026-11-01). Cap check: none.
- PackCheck pack (4 documents): recorded token usage from live-packcheck-*-v2 (2026-11-01). Cap check: none.

"Held at admission" is the worst case of the whole run (exact input bound plus the enforced output cap, one attempt per part). "Actual per run" is what the recorded tokens cost; the difference is released when the run ends, so it is available to the next run. "Cap check" counts recorded outputs that would not have fitted under the output cap the plan would have enforced: such a part would be reported as not processed (never silently wrong); 0 means every recorded answer fitted.
